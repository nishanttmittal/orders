# UNICO Orders

Client order book, production status, and dispatch PWA.

- Primary production URL: `https://unico-operations.firebaseapp.com/orders/`
- Legacy GitHub Pages fallback: `https://nishanttmittal.github.io/orders/`
- Local checks: `npm run lint` and `npm run build`

The Firebase URL is the supported iPhone home-screen installation because the
app and Firebase's Google Auth handler are same-origin there. The GitHub Pages
copy remains a browser fallback.
